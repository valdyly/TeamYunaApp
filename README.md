# Team Yuna App - Payroll & Management System

Aplikasi manajemen dan penggajian (payroll) internal yang dirancang untuk mengelola kalkulasi gaji talent/tim, penyesuaian mata uang, pemotongan kasbon, dan pembuatan slip gaji otomatis.

## 🚀 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Build Tool:** Vite
- **Cross-Platform:** Electron (Desktop) & Capacitor (Mobile)

## 🛠️ Fitur Utama

- Pengelolaan daftar talent/karyawan.
- Kalkulasi otomatis gaji, bonus, dan pemotongan kasbon.
- Konversi mata uang otomatis.
- Export & pencetakan slip gaji (PDF).
